# Legal notes

This is a practical project policy, not legal advice.

1. **No third-party proprietary material in the repo.** No console firmware, keys, BIOS files, game executables, shader dumps, or leaked source. Pull requests containing them are rejected and removed from history.
2. **Bring your own files.** Any feature that needs user-supplied files must work only with files the user is entitled to use.
3. **No circumvention tooling.** We do not build, host or document tools whose purpose is to bypass console security or DRM.
4. **Branding.** The name "AnyPC OS" and our logo are original. Do not use "PlayStation", "PS5" or similar marks in our name, logo or UI. Third-party names may appear only to describe compatibility (e.g. "AnyPS5 compatibility module") with the disclaimer in the README.
5. **Upstream credit.** Bundled or integrated projects keep their own license and attribution. AnyPS5 is an independent project and is not part of AnyPC OS.
6. **License.** Our code is GPL-3.0-or-later. Check compatibility before adding any dependency.
